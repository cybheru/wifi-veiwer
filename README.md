# WiFi Viewer

A simple Python desktop application for viewing saved Wi-Fi
profile names on a Windows computer.

## Features

- View saved Wi-Fi profiles
- Search Wi-Fi profiles
- Refresh profile list
- Copy Wi-Fi profile name
- Simple graphical interface
- Built with Python and Tkinter

## Technologies

- Python
- Tkinter
- Windows Netsh

## Requirements

- Windows
- Python 3.x

## Run

Open the project folder in VS Code.

Run:

```bash
python main.py
